# AI 配置、数据与费用

截至 2026-10-14，006–008 与正式 AI 函数已部署；部署事实见 [STATUS](../STATUS.md)。OpenAI 保留，DeepSeek 管理员健康业务开关已按许可开启，但本人用途同意和真人调用仍待验收。规则计划不依赖密钥、AI 同意或余额，也不会静默切成付费方案。

## 开关与本人同意

管理员控制 `ai_provider_settings.health_enabled`。007 初始 DeepSeek 为关闭；管理员开关不能代替本人同意。本人分别同意 `parse_schedule`、`generate_plan`、`estimate_meal_text`、`estimate_meal_photo`、`adjust_plan`，每人、每服务商、每用途独立且可撤销。OpenAI 授权不能继承给 DeepSeek，文字授权不能继承给图片。

调用前和实际发送前重新核对。任务建立时固定 provider，重试沿用原值；用户修改未来自动计划偏好不会改写旧任务。授权撤销会阻止后续发送，已经送出的内容无法追回。未知或不匹配模型、费率、预算、授权时拒绝调用，不自动更换服务。

## 实际发送范围

| 用途 | 发送内容 |
|---|---|
| 日程解析 | 当次原文、人物槽位及解释相对日期需要的提交时间 |
| 每日计划 | 本人档案相关字段、确认规则与目标日程、规则基线、有限近期训练反馈、同周其他计划的日期与训练模式 |
| 文字估餐 | 当前餐食的食物、份量、烹调、油酱等补充 |
| 图片估餐 | 当前选择、经过净化的餐食图片及必要文字补充，确实使用图片输入 |
| 餐后调整 | 当日原计划、全部已确认餐食营养字段、剩余日程、活动反馈、规则与源输入摘要；不发送照片对象或内部记录 ID |

不发送账号密码、密钥、对方私有资料或无关完整历史。模型输出须通过结构与业务规则检查；日程及餐食先由本人确认，调整建议必须再确认才能应用。手动记录无需 AI。

## 配置和预算

服务端 Secrets 保存凭据，不能放 `VITE_`、仓库、聊天或浏览器。OpenAI 使用 `OPENAI_API_KEY`、`OPENAI_MODEL`、`OPENAI_PRICE_MODEL`、输入/输出每百万 token 费率和图片 token 上限；模型与报价模型必须一致。DeepSeek 使用 `DEEPSEEK_API_KEY`，当前代码固定 `deepseek-flash`，详情见 [DeepSeek](DEEPSEEK.md)。变更模型或价格要先复核配置和预留边界。

现月度上限：全站 200 美分、OpenAI 200 美分、DeepSeek 10 美分；DeepSeek 原探针已用 5 美分、活动预留 0。用户已批准启用 DeepSeek 并做本轮最多 5 美分合成验收；不会自动提高预算，也不会把这项许可当作两人个人资料授权。新月份预算缺失时禁发。

数据库原子预留最坏费用，同时检查全站、服务商和本人用途限额；30 秒请求超时，次数和重试有界。缓存按本人、服务商、用途、输入及模型区分；已完成结果复用，已发出但结果不明的请求不自动重复付费。未发送的前置失败可有限重试。清除健康内容保留最小费用账本，不能重置额度。

本轮合成付费验收将解析、计划、图片估算和餐后调整统一按单次最多 2 美分检查；四次上界合计 8 美分，现有剩余 5 美分不保证全部完成。脚本先核对四个用途本人余额各至少 2 美分，并在每次发送前检查本轮已结算与预留增量加 2 美分不超过 5；不足时明确阻塞，不能加预算或伪造成功。

OpenAI 请求设 `store:false`；这不等于零日志，适用保存政策以[官方说明](https://developers.openai.com/api/docs/guides/your-data)为准。DeepSeek Responses 不使用会话状态也不等于零日志。本站删除不承诺供应商及备份同时擦除。ChatGPT/Codex 登录或订阅不提供本网站 API 凭据。
